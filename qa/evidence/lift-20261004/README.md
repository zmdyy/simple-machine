# 弯腰 / 蹲举：模型依据与验收（2026-10-04）

## 修复目标

原实现用同一个滑块的前后半段切换两种姿态，腰与膝的转动不连续；阻力点来自肩部的估算位置，没有对应的重物。现在使用两个姿态按钮，共享 0–100% 提起进度、箱子重量、箱子高度轨迹和腰部到重力作用线的水平距离。

## 教学模型

- 用腰骶部 L5/S1 附近的截面作为等效支点 O，不把髋部运动轴与腰部受力截面混为一处。
- 双足固定在地面；左右髋、膝、踝分别驱动肢段，双臂通过两连杆逆运动学跟随箱子。躯干与骨盆保留模型的相对装配并共同前倾，省略逐节腰椎屈伸。不是个体动作捕捉。
- 双侧髂肋肌、最长肌保留原始骨骼相对附着关系，其贡献合并为腰背伸肌合力。5 cm 是固定的等效力臂，不是某根肌纤维的测量值。
- 课堂假设：箱子重力 100 N（约 10 kg，g 取 10 N/kg），上身重力 300 N；上身质心相对 O 的静止偏移为向上 25 cm、向前 2 cm。质心、角度与力臂是教学参数，不是研究测得的标准人体数据。
- 在矢状面准静态条件下，`F肌 × 0.05 = 100 × d重物 + G上身 × d上身`。力矩先在三维世界坐标求解，再投影到画面；转动观察相机不改变计算。
- 支点反力不产生关于 O 的力矩，故在此力矩示意中省略；没有求解完整人体平衡、关节反力、压缩/剪切载荷、加速度、腹压、共同收缩及疲劳。
- 上身自重关闭时，同重、同距离的两种姿态得到相同的重物力矩和肌肉合力；开启后比较上身倾斜带来的额外力矩。站直终点两种姿态一致。
- 箱子初始已被提在膝部附近，本动画展示持物起身过程，不模拟从地面抓握。手指保留原始骨骼形态，掌部对齐箱子两侧上缘，省略握指动画。

## 资料与使用边界

1. von Arx et al. (2021), *From Stoop to Squat: A Comprehensive Analysis of Lumbar Loading Among Different Lifting Styles*. [原始研究](https://www.frontiersin.org/journals/bioengineering-and-biotechnology/articles/10.3389/fbioe.2021.769117/full)，DOI: 10.3389/fbioe.2021.769117。30 名健康参与者举 15 kg 箱子的肌骨模型研究；不同动作、节段、压缩和剪切载荷的排序并不一致。用于提醒：简单的肌肉力矩模型不能推出“蹲举一定更安全”，也不能把肌肉合力当作椎间盘压力。本模型不复现该论文的人体或数值结果。
2. [CDC/NIOSH Revised NIOSH Lifting Equation](https://www.cdc.gov/niosh/ergonomics/about/rnle.html)。搬举评估同时考虑重量、水平距离、高度、行程、非对称角、频率、持续时间和抓握等因素。本课堂只提取“距离值得独立比较”的原则；NIOSH 的水平距离基准是两踝中点，本课堂力臂基准是 O，两者并非同一定义，没有实现或计算 RNLE 风险指数。

## 运行与验收

依赖：`npm install --no-save --package-lock=false playwright@1.55.0 three@0.160.0`，`npx playwright install chromium`。

在仓库根目录启动 `python3 -m http.server 5500` 后：

```sh
node qa/body-lift-qa.mjs
node qa/body-neck-qa.mjs
node qa/body-controls-qa.mjs
```

搬举测试覆盖 2 种姿态 × 3 个距离 × 7 个进度，共 42 个姿态；检查髋膝踝及肩肘连接、手掌跟箱、腰背肌附着、力矩闭合、肌肉力正值、三维垂直力臂、上身开关、距离控制、相机旋转、动作来回切换、播放、抽象视图恢复和窄屏。`report.json` 记录最大误差。实际浏览器截图用于复核装配和标注；数值连接检查只验证简化模型的一致性，不代表临床有效性。
