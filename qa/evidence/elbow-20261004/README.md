# 搬举肘关节方向修正

用户截图指出弯腰与蹲举的肘部均向前折。原因是肩—腕两段逆向运动学选择了前方肘部解；旧验收只检查连接、抓握与力矩，没有检查肘部弯曲方向。

修正为后方肘部解，同时用共同屈伸轴约束肱骨和前臂骨的旋转，避免仅对齐肢段长轴造成骨骼扭转。双手的提手定位保持由独立抓握模型计算。

在原有 42 组搬举姿态（两种动作、三种起始距离、七个进度）中新增双肘方向检查：从实际骨段变换重新取得肩、肘、腕坐标，检查肘在肩腕连线后方、屈伸轴方向正确；继续检查关节连续、手不离开提手及手骨不穿入箱体。另保留 20 组髋膝受力、动作切换、抽象恢复和移动端回归。

截图包含两个动作的中间姿态，报告记录实际骨段坐标及屈肘角度。
