# 举哑铃装配修复与验收

## 原因

现有 GLB 是静态网格，没有皮肤权重或屈肘动画。旧逻辑只转动部分前臂骨骼，肌肉没有变形；腕骨选择不全，指骨没有包含在可见结构中。关节标记节点不是骨骼网格，旧的网格搜索无法找到它们，因而使用了不合适的中心点回退。桡骨粗隆名称匹配也没有命中。

## 修复

- `js/curl-rig.js` 为当前 GLB 建立单臂模板，按完整解剖名称选择桡骨、尺骨、8 块腕骨、5 块掌骨和 14 块指骨，共 29 块随动骨骼。
- 在模型原始米制坐标中校准肘轴；肱二头肌与肱肌的远端分别贴合桡骨和尺骨的实际三角面。坐标针对当前资产，替换模型后需要重新校准。
- 肩端固定，肌腹随屈肘缩短，远端肌腱随骨附着并保持长度；每次从原始顶点计算，切换动作时恢复原始几何体。
- 动力点与肌腱附着点共用坐标。力臂仍在三维中计算；SVG 标注考虑画布尺寸和 SVG 留白，并在旋转、缩放及窗口变化时更新。
- 屈肘模板禁用拆解滑块，避免拆开肌骨连接。骨、肌显隐与视角旋转保留。

## 验收

2026-09-27，Chromium / Playwright 1.55.0 / Three.js 0.160.0：

- 屈肘 21 个姿态，含伸展和最大屈曲；检查肌腱与骨表面距离、肩端稳定性、肌腱长度。
- 检查 29 块随动骨骼完整性，以及隐藏后恢复。
- 检查相机旋转不改变力臂、标注投影误差小于 1 像素、窗口缩放和动作切换复位。
- 回归踮脚的三个姿态、第二类杠杆关系、相机不变性和动作切换。
- 检视无标注的解剖截图及带标注截图；检查浏览器异常。

结果与截图位于 `qa/evidence/curl-20260927/`。距离数值只证明程序中的连接稳定，不代表解剖测量精度。

复现：

```sh
npm install --no-save --package-lock=false playwright@1.55.0 three@0.160.0
npx playwright install --with-deps chromium
python3 -m http.server 5500
# 在另一个终端运行：
node qa/body-curl-qa.mjs
node qa/body-calf-qa.mjs
```

测试把固定版本 Three.js 的 CDN 请求映射到同版本 npm 文件，使验收不依赖公网 CDN 可达性；这不是 CDN 可用性测试。模型与 Draco 解码器仍使用仓库资产。

## 教学范围

参考用户上传视频中肌腱持续连接、肌腹缩短的运动关系，保留现有低多边形资产。本模板固定上臂、保持前臂旋后，仅展示屈肘；没有重建完整肌纤维、前臂旋转、软组织接触或医学级生物力学。课堂说明已标明简化范围。
